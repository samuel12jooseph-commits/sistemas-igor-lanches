# 🍔 Sistema Web - Igor Lanches

Sistema web responsivo para gerenciamento de pedidos de uma lanchonete, desenvolvido como projeto prático de portfólio.

## 🚀 Principais funcionalidades

- Cardápio digital e criação de pedidos
- Acompanhamento do status do pedido pelo cliente
- Painel administrativo com autenticação
- Gestão de produtos e clientes
- Dashboard administrativo
- Controle financeiro e relatórios
- Backup de dados
- Integração com Firebase Authentication e Cloud Firestore
- PWA com `manifest.webmanifest` e Service Worker

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Cloud Firestore
- PWA / Service Worker

## 📁 Estrutura do projeto

- `index.html` — página inicial
- `cardapio.html` — cardápio e fluxo de pedidos
- `acompanhar.html` — acompanhamento do pedido
- `admin/` — login e módulos administrativos
- `js/` — lógica da aplicação
- `css/` — estilos da interface
- `firebase/` — configuração da integração com Firebase

## 🔐 Segurança

A configuração pública do cliente Firebase identifica o projeto, mas a proteção dos dados depende das regras do Firebase Authentication e Firestore. Credenciais de usuários administrativos não são armazenadas neste repositório.
